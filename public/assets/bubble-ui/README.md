Bubble Sort cartoon UI

Original SVG artwork created for this project: blue number blocks, green/yellow/blue buttons, cream dialogue, speech tail, and outlined icons. Panels use 12px nine-slice borders; blocks and icons are image assets. Labels remain accessible HTML. Existing Buta artwork and audio are preserved.

Current palette: lavender #9191FF background, yellow #FFDB3B buttons, pale lavender #EFEDFF dialogs, dark outlines.
